# Ben 10 Mod — Minecraft 1.7.10 (Forge)

Фан-мод по мотивам Ben 10: Омнитрикс с 10 классическими пришельцами,
враждебные мобы (ДНКалиены, Хайбриды), босс Вилгакс и отдельное измерение
Null Void.

## ⚠️ Важно: это исходный код, не готовый .jar

Я собрал полный набор Java-исходников, ресурсов и `build.gradle`, но **не
могу скомпилировать готовый `.jar` в этой среде** — у меня нет доступа в
интернет, а сборка мода под Forge 1.7.10 требует скачивания Forge MDK,
Minecraft-библиотек и MCP-маппингов через Gradle. Поэтому в архиве —
проект, готовый к сборке, а не бинарник.

Код написан по стандартному Forge 1.7.10 API (проверено по памяти, без
компилятора под рукой), так что не исключены мелкие несостыковки при первой
сборке — обычно это 1-2 правки импорта/сигнатуры метода, ниже описано, что
делать.

## Как собрать самому (10-15 минут)

1. Установите **JDK 8** (обязательно 8, более новые Java не подходят для
   ForgeGradle 1.x).
2. Распакуйте архив в отдельную папку.
3. В папке проекта выполните:
   ```
   gradlew.bat setupDecompWorkspace build      (Windows)
   ./gradlew setupDecompWorkspace build         (Linux/macOS)
   ```
   Gradle wrapper (`gradlew`) в архиве не хватает бинарного `gradle-wrapper.jar` —
   при первом запуске сгенерируйте его: `gradle wrapper --gradle-version 2.14`
   (нужен установленный Gradle 2.x), либо просто откройте проект в IntelliJ IDEA
   с плагином Forge/ForgeGradle — он всё сделает сам.
4. Первый запуск скачает Forge 1.7.10-10.13.4.1614-1.7.10 и создаст
   декомпилированный workspace — нужен интернет и может занять время.
5. Готовый мод появится в `build/libs/bin10mod-1.0.0.jar`.
6. Киньте jar в папку `mods` вашего Forge-клиента 1.7.10.

Если что-то не компилируется — почти наверняка это несовпадение сигнатуры
метода `WorldProvider`/`Entity`/`Item` с вашей версией MCP-маппингов;
киньте мне текст ошибки, я поправлю.

## Что реализовано

- **Омнитрикс** (`item.omnitrix`) — крафтится из золота, редстоуна и алмаза.
  - ПКМ — переключить выбранного пришельца (сообщение в чат).
  - Shift+ПКМ — превратиться / вернуться в человека.
  - Трансформация длится 5 минут, после отключения — 20 секунд перезарядки.
- **10 пришельцев**, каждый со своими игровыми эффектами (без смены модели
  игрока — это отдельная большая задача, см. "Ограничения" ниже):
  Heatblast, XLR8, Four Arms, Diamondhead, Wildmutt, Grey Matter, Stinkfly,
  Upgrade, Ripjaws, Ghostfreak.
- **Мобы**: DNAlien (рядовой враг), Highbreed (усиленный враг) — оба дропают
  «Образец ДНК».
- **Босс Вилгакс** — 200 HP, призывает подкрепление DNAlien-ов в бою, крупный
  дроп при смерти.
- **Измерение Null Void** — тёмное пространство с тонким полом. Попасть туда
  можно через предмет «Проектор Пустоты» (крафтится из железа, эндер-жемчуга
  и образцов ДНК) — повторное использование в Пустоте возвращает обратно.
- Блок `null_void_stone` для строительства.
- Локализация: русский и английский.

## Ограничения / что можно доделать

- **Визуальная трансформация игрока не реализована.** Полноценная смена
  3D-модели/скина игрока на пришельца в 1.7.10 требует кастомного рендера
  игрока (`RenderPlayer` hook) и отдельных моделей под каждого пришельца —
  это сопоставимо по объёму с отдельным мини-проектом. Сейчас трансформация
  даёт полный набор игровых способностей (скорость, огнестойкость, урон и
  т.д.), но модель персонажа не меняется.
- Мобы временно используют модель зомби как заглушку рендера — я сгенерировал
  простые плейсхолдер-текстуры (16×16, однотонные с рамкой), их стоит
  заменить на нормальный арт.
- Портал в Null Void — через предмет-телепорт, а не классическая рамка портала
  (это сильно упрощает и стабилизирует код; рамку можно добавить позже).
- Нет GUI-отображения текущего пришельца/таймера — только чат.

```
  alien/AlienForm.java       — 10 пришельцев и их эффекты

  entity/boss/EntityVilgax.java
  dimension/                 — WorldProvider, биом, телепортер для Null Void
  handler/PlayerTickHandler.java
  proxy/                     — Common/ClientProxy

  mcmod.info
  assets/bin10mod/lang/      — ru_RU, en_US
  assets/bin10mod/textures/  — плейсхолдер-иконки
```
